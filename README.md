# ЕТИЧНИЙ ВИБІР · v0.1.0

Навчальний вебсимулятор етичних дилем для сектору безпеки та оборони України.

## Поточний стан

**Foundation / UI prototype:** головна сторінка, каталог, огляд сценарію «Послуга для знайомого», адаптивна темна тема, JSON-дані сценаріїв. **Інтерактивне проходження, повний Scenario Engine, групове голосування та перевірені правові джерела ще не реалізовані.** Не використовуйте цю версію як готовий навчальний курс.

## Локальний запуск

Потрібен Node.js 20.19+ або 22.12+.

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).

Перевірка збірки:

```bash
npm run build
```

## Архітектура

- `src/pages` — сторінки застосунку
- `src/components` — повторно використовувані компоненти
- `src/scenarios` — сценарні метадані у JSON, незалежно від UI
- `src/types` — контракти TypeScript
- `src/styles` — дизайн-система

## Етика та захист даних

- Не запитуємо і не зберігаємо персональні дані.
- Не використовуємо службову інформацію чи реальні ідентифіковані кейси.
- Приклад сценарію є чернеткою з допомогою ШІ, **не перевіреною фахівцем**.
- Правові джерела не заповнено, тому не заявляємо про юридичну верифікацію.
- Не використовувати для оцінки професійної придатності людей.

## Наступні етапи

1. Типізований граф сценаріїв та Scenario Engine.
2. Два завершені багатокрокові сценарії (не менше 3 послідовних етапів кожен), відкладені наслідки, пояснюваний звіт.
3. Анонімні групові сесії з ведучим і агрегованим голосуванням.
4. Юридична та фахова перевірка джерел; тестування; демовідео та записка про використання ШІ.

Джерело вимог: наданий організаторами документ «Завдання 1. Симулятор етичних дилем».
