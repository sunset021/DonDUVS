# ЕТИЧНИЙ ВИБІР

Навчальний вебсимулятор етичних дилем для сектору безпеки та оборони України, розроблений командою **ДонДУВС** у межах хакатону (*Building Integrity Hackathon 2026*). Проєкт допомагає моделювати складні етичні й правові ситуації, оцінювати наслідки рішень та проводити як індивідуальну практику, так і групові обговорення.

## Проблема і користувач

**Проблема:** У секторі безпеки та оборони курсанти, слухачі та молоді фахівці часто стикаються з ситуаціями, де теорія права й доброчесності не дає миттєвої відповіді на неформальний тиск — прохання «по дружбі», конфлікт інтересів, неповну вихідну інформацію, авторитет керівництва чи тиск середовища під час перевірок та сесії. Бракує безпечного, інтерактивного й відтворюваного середовища для тренування таких рішень до або під час реальної службової діяльності.

**Цільовий користувач:**
* **Курсанти й слухачі закладів вищої освіти сектору безпеки та оборони** (зокрема ДонДУВС) — для самостійного тренування та підготовки до практичних занять.
* **Діючі фахівці правоохоронних органів і сектору безпеки та оборони** (зокрема учасники курсів підвищення кваліфікації) — для аналізу типових етичних і процедурних ризиків у службовій діяльності.
* **Викладачі доброчесності, професійної етики, антикорупційної політики та модератори/куратори** — для проведення інтерактивних занять і групових розборів у навчальних групах.

## Що робить рішення

Вебсимулятор **«ЕТИЧНИЙ ВИБІР»** реалізує інтерактивне проходження сценаріїв етичних дилем і надає інструменти для самоперевірки та аудиторної роботи:
* **Каталог та огляд сценаріїв:** дозволяє обрати сценарій (зокрема *«Послуга для знайомого»* — `favor-for-friend` та *«Академічна підтримка чи неправомірна вигода»* — `supervisor-pressure`), переглянути опис конфлікту цінностей, цільову аудиторію, орієнтовний час проходження, рівень складності та нормативно-правові орієнтири.
* **Багатокрокове проходження (послідовні етапи):** кожен сценарій веде користувача через кілька етапів ситуації з вибором варіантів дій, де рішення впливають на подальший перебіг і підсумок.
* **Динамічні показники та аналітичний розбір:** відстежує зміну ключових індикаторів (зокрема доброчесність, довіра колективу та інституційна довіра) і формує пояснення наслідків замість сухих формальних оцінок.
* **Два режими роботи:** підтримує індивідуальне проходження та груповий режим / сесії для обговорення та голосування під керівництвом ведучого чи викладача.
* **Зручність роботи в інтерфейсі:** адаптивна тема оформлення, налаштування розміру тексту та перемикання мови інтерфейсу.

## Як запустити

Розробка, редагування та перевірка проєкту виконувалися у **Visual Studio Code**. Для локального запуску потрібен **Node.js 20.19+** або **22.12+**.

1. Клонуйте репозиторій та перейдіть до каталогу проєкту:

```bash
git clone [https://github.com/sunset021/DonDUVS.git](https://github.com/sunset021/DonDUVS.git)
cd DonDUVS
1. Відкрийте папку проєкту у Visual Studio Code (або запустіть команди у вбудованому терміналі VS Code):
code .
npm install
2.Запустіть застосунок у режимі розробки:npm run dev
Відкрийте адресу, яку виведе Vite у терміналі (зазвичай http://localhost:5173).
Для перевірки production-збірки виконайте:npm run build
Як влаштовано
Проєкт створено й структуровано у Visual Studio Code з розмежуванням логіки інтерфейсу, типів даних, сценарного контенту та документації:

src/pages/ — сторінки застосунку (головна сторінка, каталог сценаріїв, огляд дилеми, проходження сценарію, груповий режим).

src/components/ — повторно використовувані UI-компоненти та картки етапів/рішень.

src/scenarios/ — сценарні дані та конфігурації у JSON / модулях сценаріїв, відокремлені від логіки відображення.

src/types/ — описи типів і контракти TypeScript.

src/styles/ — стилі та дизайн-система застосунку.

docs/ — проєктна документація, опис сценаріїв/логіки оцінювання та записка про використання ШІ.

Етика та захист даних: застосунок не запитує, не зберігає та не обробляє персональні дані користувачів, службову інформацію з обмеженим доступом або реальні ідентифіковані кейси. Усі ситуації та персонажі є синтетичними/навчальними і не призначені для оцінки професійної придатності конкретних осіб.

Документація
docs/scenarios_and_logic.md — опис сценаріїв (favor-for-friend, supervisor-pressure), таблиця кейсів, карта рішень та логіка оцінювання.

docs/ai.md — записка про використання інструментів ШІ під час підготовки проєкту.
